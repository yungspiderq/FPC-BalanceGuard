# 💳 BalanceGuard — контроль баланса

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

**Автор:** yungspider

Баланс FunPay меняется тихо: возврат списал деньги, вывод ушёл не туда, а доступный
остаток кончился в самый неподходящий момент. Плагин сверяет баланс по расписанию
и сразу пишет в Telegram, если требуется ваше внимание.

## Возможности

- 💳 **`/balance`** — общий и доступный к выводу остаток **по всем валютам** одним сообщением.
- 📈 **Динамика за 24 часа** по наблюдаемой валюте: сколько прибавилось/убыло.
- ⚠️ **Низкий доступный остаток** — алерт при падении ниже `minAvailable`, с гистерезисом:
  повтор не чаще `alertCooldown`, и отдельное «баланс снова выше порога», когда пополнили.
- 🔻 **Неожиданное списание** — общий баланс уменьшился больше чем на `dropThreshold`:
  возврат по заказу, вывод средств или доступ к аккаунту у кого-то ещё.
- 💰 **Поступления** на баланс (включается `notifyOnGrow`).
- 🧵 Все запросы к FunPay — в отдельном потоке: поллинг Telegram не блокируется.
- 💾 Замеры хранятся на диске, поэтому динамика есть и сразу после перезапуска бота.

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-BalanceGuard/main/balance_guard.py -O plugins/balance_guard.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

Команда **`/balance`** — текущий баланс, изменение за 24 часа и время обновления.
Запрос к FunPay выполняется в отдельном потоке, сначала бот отвечает «запрашиваю баланс».

### Пример ответа

```text
💳 Баланс FunPay

₽ Общий: 12 500.50  |  Доступно: 3 200.00
$ Общий: 84.20  |  Доступно: 84.20

📈 Изменение общего баланса (RUB) за 24 ч.: +1 250.00 ₽

Обновлено: 24.10.2026 15:45:42
```

## Настройки

Файл `storage/plugins/balance_guard.cfg` создаётся при первом запуске и **перечитывается на лету** — перезапуск бота не нужен.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `1` | фоновые проверки баланса |
| `checkInterval` | `15` | интервал проверок, минут |
| `currency` | `RUB` | за какой валютой следить: `RUB` / `USD` / `EUR` |
| `minAvailable` | `500` | порог доступного остатка |
| `dropAlert` | `1` | алерт об уменьшении общего баланса |
| `dropThreshold` | `1` | минимальная сумма списания для алерта |
| `notifyOnGrow` | `0` | уведомлять о поступлениях |
| `growThreshold` | `1` | минимальная сумма поступления |
| `alertCooldown` | `120` | пауза между повторными алертами, минут |
| `keepHistory` | `1` | хранить замеры для динамики за 24 часа |

## Важно знать

- Получение баланса — это **два дополнительных запроса к FunPay** (так устроен сам Кардинал:
  баланс достаётся через страницу лота), поэтому интервал по умолчанию 15 минут.
  Не ставьте меньше 5 минут на активном аккаунте.
- Первый замер после запуска — базовый: уведомлений по нему не будет, иначе бот «пугал» бы
  вас после каждого рестарта.
- Списание и поступление считаются по **общему** балансу наблюдаемой валюты, порог —
  по **доступному** остатку.
- Настройки: `storage/plugins/balance_guard.cfg`, замеры: `storage/plugins/balance_guard.json`.

## Состав репозитория

- `balance_guard.py` — плагин (класть в `plugins/`).
- `tests_plugin_balance_guard.py` — функциональные тесты на моках (31 проверка: метаданные и загрузка
  через `Cardinal.load_plugin()`, все хэндлеры событий, команды Telegram, фоновые потоки и выход
  по смене `run_id`, алерты, cooldown'ы, дедупликация событий, удаление плагина).
- `tests_integration_balance_guard.py` — интеграционные тесты (20 проверок): плагин грузится
  **настоящим** `Cardinal` и проходит боевой путь `load_plugins()` → `add_handlers()` →
  `run_handlers()` → `toggle_plugin()`, плюс утверждение «в логах бота ноль ошибок».
  Запуск из корня FunPayCardinal:
  ```bash
  cp tests_plugin_balance_guard.py tests_integration_balance_guard.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt
  python3 tests_plugin_balance_guard.py && python3 tests_integration_balance_guard.py
  ```
  Тесты сами найдут Кардинал и в другом месте: `FPC_PATH=/opt/FunPayCardinal python3 tests_plugin_balance_guard.py`.
  Сетевые объекты подменены заглушками — реальных запросов к FunPay и Telegram тесты не делают.
